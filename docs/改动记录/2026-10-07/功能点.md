# BorderCart 核心版硬裁剪

## 需求

将项目发布版裁剪为跨境电商 AI Agent 的核心演示，保留多 Agent 协作、商品 RAG、AgentScope KnowledgeBase、Personal Skill、交易确认、SQLite、本地 Qdrant、FastAPI/AG-UI 和 React/Vite；物理移除非核心扩展。

## 具体变更

- 删除 Redis、队列、worker、语义缓存、Prompt/Capability Registry、公共 Skill、Harness、Web Search、HTTP reranker、Langfuse/OTLP tracing 及其测试和评测脚本。
- 组合根固定为单进程本地事件总线、进程内限流/熔断、SQLite、本地 Qdrant、商品 Embedding、KnowledgeBase 和三个 Agent。
- 商品检索保留 Embedding + Qdrant 召回，移除二阶段精排；Personal Skill 保留买家创建、读取、删除、隔离和上下文注入。
- README、`.env.example`、Compose、Makefile 改为 BorderCart AI 核心版说明；默认集合名和 SQLite 文件名改为 `bordercart_*`。
- 保留 `.env` 及用户已有未提交文件，不提交任何密钥、数据库或买家原文。

## 未完成项

- `uv.lock` 尚未用可用 uv 重锁，需在有 uv 的环境执行 `uv lock` 后复核依赖指纹。
- 仓库中仍有少量历史内部标识符（例如旧 localStorage key 和模块注释），不影响运行；前端可见品牌已统一为 BorderCart AI。

## 配置启用与回滚

核心版启用：复制 `.env.example` 为 `.env`，填写模型和 Embedding 配置，`QDRANT_URL` 留空即使用 `DATA_DIR/qdrant` 本地模式。回滚只能通过 Git 提交恢复，不能删除 `data/` 或覆盖用户 `.env`。
